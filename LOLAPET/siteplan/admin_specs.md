# Especificaciones de la Zona Admin (Estilo WooCommerce)

* **Autenticación:** Acceso protegido por contraseña para administradores vía endpoints privados o Airtable Interface Designer.
* **Catálogo:** Listado con miniatura, nombre, SKU, precio regular/oferta, stock en tiempo real y switch de publicación activa/pausada.
* **Ficha de Producto:** Soporte para productos simples y variables (selector de peso/talla con SKU y stock individual).
* **Gestión de Pedidos:** Filtros por estado (Pendiente, Pagado, Enviado, Sobreventa) con botón directo para contactar al cliente por WhatsApp.
* **Control de Fletes y Cupones:** Modificación de tarifas por comuna y creación de códigos de descuento.
